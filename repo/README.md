# 我，地图和小女仆

> 愿你在这里遇见喜欢的历史。

一册可以捧在手里转动的世界历史地球仪：从 300 万年前的东非营地到 1826 年的广州十三行，拖动时间轴，看势力版图在星球上生长与消退；点开一个国家，读它的制度、经济、军事与文化；打开人物关系网，看历史的群星如何彼此牵连。还有一位小女仆住在地图里，陪你一起跨越时间。

本项目完全开源、永久免费，遵循《123 公约》（见 [COVENANT.md](COVENANT.md)）。

---

## 三个版本

| 版本 | 内置模块 | 适合谁 | 安装包 |
|---|---|---|---|
| 纯净版 | 无 | 只要最核心的历史地球仪 | 见 [Releases](../../releases/latest) |
| 历史版 | 中国古代历史补充、世界势力资料补充、神话时代补充 | 大多数读者（**推荐**） | 见 [Releases](../../releases/latest) |
| 完整版 | 全部六个模块 | 想要女仆、背景音乐和自定义地图的完整体验 | 见 [Releases](../../releases/latest) |

三个版本可以共存，互不影响。未内置的模块也可以随时在程序里装卸（见 `modules/`）。

## 功能一览

- **可旋转的 3D 历史地球仪**：缩放、旋转、昼夜与地形图层，海岸线与河流随时代可见
- **时间轴（前 300 万年 — 1826 年）**：拖动缓动追击，大跨度跳转播放「跨越时间」过场
- **势力版图与详情**：每个势力都有简介、制度、经济、军事、文化、事件与出处
- **资料搜索**：人物 / 势力 / 名词 / 神话，输入即出建议，点击直达详情
- **人物关系网**：星空中的人物星球，节点如星闪烁，可搜索、可聚焦某个势力的当代群像
- **模块系统**：六个官方模块 + 自定义模块模板，任何人都能为这册地图写新模块
- **小女仆**（完整版）：住在地图里的 Q 版女仆，随时代换装，会闲聊、会感慨，也会在你跨越时间时跳进虫洞
- **自定义地图创建**（完整版）：在空白星球上画自己的世界——陆地、海洋、势力、地形、建模，一应俱全

## 安装

1. 到 [Releases](../../releases/latest) 下载对应版本的安装程序，双击运行（国内下载慢的话，可看置顶评论/简介里的网盘镜像）；
2. 安装不需要管理员权限，装完桌面会出现「我，地图和小女仆」；
3. 首次打开会请你签署《123 公约》并落款——你的名字会出现在程序的称呼里。

详见 [安装说明.md](安装说明.md)。使用方法见 [使用说明.md](使用说明.md)。

**系统要求**：Windows 10 / 11（系统自带 Edge WebView2 即可，无需安装浏览器或其他运行环境），约 1.2 GB 磁盘空间。

## 模块生态

[`modules/`](modules/) 是六个官方模块的源码，每个都是一个独立的 `.js` 文件：

| 模块 | 作用 |
|---|---|
| 中国古代历史补充 | 数千位中国人物、势力四维详情、典章名词 |
| 世界势力资料补充 | 世界各势力的资料补全 |
| 神话时代补充 | 各文明神话体系与神祇谱系 |
| 女仆模块 | 住在地图里的小女仆 |
| 背景音乐模块 | 导入自己的音频，截取片段做背景音乐 |
| 自定义地图创建模块 | 空白星球 + 全套绘制与建模工具 |

想写自己的模块？读 [`source/自定义模块模板（AI开发套件）V3.md`](source/自定义模块模板（AI开发套件）V3.md)——这份模板就是设计来可以**直接丢给 AI**，让它写出能完美装载的模块的。写好的模块欢迎寄回给我（见公约第九条的精神：来而不往，非礼也）。

## 源代码说明

整个程序是**一个 HTML 文件**：地图引擎、资料库、界面、六个内置模块全部在内。受 git 单文件 100 MB 限制，源码以两种 zip 形式挂在 [Releases](../../releases/latest) 附件里：

- **`我，地图和小女仆-源码.html.zip`**（约 250 MB）：单文件母本，所有修改都在它上面进行；解压后用浏览器打开即可运行（受浏览器内存所限，更推荐用安装包的独立窗口）；
- **`我，地图和小女仆-拆分版源码（历史版·代码壳+数据包）.zip`**（约 240 MB）：由母本拆分出的「22 MB 代码壳 + 25 个数据块」——**想读代码建议看这个**，壳是人类可读的源码，数据块按类别分文件，这也是安装包实际运行的形态。本地起个静态服务器（如 `python -m http.server`）打开 `program.html` 即可运行。

`source/tools/` 里的脚本负责单文件 ⇄ 拆分版的互转与三变体生成；纯净版、完整版的拆分形态可用同一套脚本生成。
